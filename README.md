# Teacher-Health-Guided Release of Differentially Private Speech Classifiers under Class Imbalance

Yadi Wen, Yaxuan Wang, Dan Yu, Rong Du, Yue Fu, and Yongle Chen  
Taiyuan University of Technology

[Paper](main.pdf) · [Supplement](Supplementary_Material.pdf) · [Reproducing the experiments](code/README.md)

This repository contains the implementation, experiment configurations, split
manifests, and recorded results for the paper. Teacher-Conditioned Release
Distillation (TCRD) chooses whether to exclude, attenuate, or fully use a private
teacher's targets before training the released student. The comparison includes
hard-label training, standard KD, health-aware KD, global-temperature CTKD,
simple routing rules, and matched PATE controls.

The main CV17 study uses 50,000 training clips, ten client-grouped partitions,
five noise levels, and separate checkpoint-selection and health-calibration
sets. TCRD improves mean balanced accuracy over Hard by 2.20 percentage points
on this grid. Composite health does not predict KD gain better than balanced
accuracy alone, and mean-matched constant attenuation performs similarly to
instance HAKD. The smaller accent and emotion studies include cases where
low-health routing rejects beneficial distillation.

## Installation

The recorded CV17 environment uses Linux, Python 3.13, PyTorch 2.11.0 with CUDA
12.8, and Opacus 1.6.0. Training and feature extraction use an NVIDIA GPU; the
tests and rendering commands below also run on a CPU.

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install torch==2.11.0 torchaudio==2.11.0 --index-url https://download.pytorch.org/whl/cu128
python -m pip install -r code/requirements.txt
cd code
python -m pytest -q tests
cd ..
```

The [experiment guide](code/README.md) gives data preparation and training
commands for each protocol. Run outputs go into new directories under
`code/outputs/`; the supplied `results/` directory is the paper's recorded data.

## Recreate the figures and tables

These commands use the included JSON/CSV records and do not require audio,
model downloads, or a GPU. They write to `outputs/paper/` without changing the
paper's source figures.

```bash
mkdir -p outputs/paper/figure
python code/tools/render_cv17_results.py --audit results/cv17_release_20260908/audit --latex outputs/paper
python code/tools/plot_cv_replacement.py --evidence results/cv_primary_replacement_20260907/independent_evidence.json --out outputs/paper/figure
python code/tools/restore_old_visuals.py --results results --cv-evidence results/cv_primary_replacement_20260907/independent_evidence.json --manifests results/cv17_download_manifests --latex outputs/paper
```

This regenerates Figs. 2–8 and the generated table fragments. Figure 1 is
provided as vector PDF/SVG in `figure/`, together with its original vector
base and local-correction script. The manuscript uses vector PDF figures.

## Data and recorded results

Exact clip/client manifests are included for CV17 and the small Common Voice
archive, together with VCTK split CSVs and IEMOCAP utterance/speaker manifests.
The experiment guide links to the source datasets and pretrained encoders.
Audio, extracted feature arrays, model checkpoints, and evaluation-logit arrays
are obtained or regenerated by the documented preparation and training steps;
they are not stored in this Git repository.

The JSON/CSV records support the reported summaries and figure generation.
Checkpoint-to-prediction verification additionally uses the files produced by
training, through the corresponding `audit_*` scripts. Recorded absolute paths
identify the original runs; `replay_recorded.py` relocates inputs and outputs
for the VCTK and additional small-archive experiments.

Privacy accounting is per private-teacher training condition, at the record
level. Auxiliary and development data are permitted side information.
Public-benchmark seeds are retained for reproduction; an actual private
deployment needs undisclosed privacy noise and accounting for all inspected
private-training runs. Source datasets and pretrained models retain their
respective access and licensing terms.

## Build the paper

With TeX Live and `latexmk` installed, run `make all` from this directory.
`main.tex` is the main document for Overleaf. The supplied manuscript and
supplement contain ten and four pages, respectively.

The PDF check also requires Poppler (`pdfinfo`, `pdffonts`, `pdfimages`,
`pdftotext`) and Ghostscript:

```bash
mkdir -p outputs
python code/tools/verify_paper_build.py --latex . --submission-stage initial --without-response --out outputs/paper_build_check.json
```
